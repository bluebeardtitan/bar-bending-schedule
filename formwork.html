How to use

TabMove to next field
EnterAdd member to schedule (from any field)
EscReset form
Alt+IOpen/close Project Info
Alt+SOpen/close Settings
  1. Fill Member → Element → Grade → Section → Dimensions → Length → Nos → Formwork → Add.
  2. Concrete volume = section area × length × nos. Formwork = shutter perimeter × length × nos (+ end faces).
  3. Click ✏️ Draw to sketch the cross-section. The drawer opens in the Line · No Texture style — pick a rebar texture from the Texture tool if you want ribbed bars.
  4. Use CSV / Save / Export PDF — all exports include project info and the grade summary.
